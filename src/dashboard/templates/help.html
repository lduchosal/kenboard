Aide — utiliser le kenboard

Bots Le ken pour les agents

Piloter le board depuis un agent LLM (Claude, GPT…) ou un terminal, via la CLI ken.

1. Installer

python3 -m venv .venv && source .venv/bin/activate
pip install kenboard

2. Configurer

Le plus simple : sur une catégorie, cliquez Copy onboard link et collez l'URL à votre agent — il récupère un runbook complet et s'auto-configure. Sinon, créez un fichier .ken (mode 0600) :

project_id=<UUID du projet>
base_url={{ base }}
api_token=<clé API depuis /admin/keys>

Générez la clé sur /admin/keys (scope read ou write sur le projet).

3. Travailler

ken list --who Claude --status todo
ken show <id>
ken add "MODULE / Titre" --desc "…" --who Claude --status todo
ken move <id> --to doing
ken move <id> --to review

Workflow : todo → doing → review → done. L'agent gère jusqu'à review ; seul l'humain finalise en done.

Extension Le ken pour le navigateur

Capturer l'onglet courant comme tâche en un raccourci (titre + URL + plan textuel de la page), ou surligner du texte sur la page et tout pousser en bloc.

1. Télécharger

Chaque release attache l'extension : github.com/lduchosal/kenboard/releases → kenboard-extension-<version>.zip. Dézippez-la localement.

2. Installer

Chrome / Edge / Brave : chrome://extensions/ → activer le Mode développeur → Charger l'extension non empaquetée → choisir le dossier dézippé.

Firefox (temporaire) : about:debugging#/runtime/this-firefox → Charger un module temporaire → manifest.json.

Firefox (permanent) : installez le .xpi signé via about:addons → ⚙ → Installer un module depuis un fichier. Il survit aux redémarrages.

3. Configurer

Cliquez l'icône de l'extension → Réglages, puis collez votre Copy onboard link dans le champ Onboarding link : l'URL de base, le projet et le token se remplissent automatiquement. Cliquez Test connection puis Save.

4. Capture rapide (popup)

Raccourci Ctrl+Shift+K (macOS : Cmd+Shift+K), ou l'icône de la barre d'outils. Le titre et l'URL de la page sont pré-remplis, plus un plan h1–h3 et la sélection courante si tu en avais une ; éditez, puis Save. La tâche atterrit en todo dans le projet configuré.

5. Annoter une page (paintbrush)

Raccourci Alt+P (macOS : Option+P) sur n'importe quelle page normale : un badge kb · 0 apparaît en haut à droite, accompagné d'une mini-palette ▭ Rectangle (R) / T Texte (T).

Outil rectangle (actif par défaut) : drag sur la page pour encadrer un élément. L'extension récupère le texte sous le rectangle pour le mettre dans la description de la tâche. Outil texte (touche T) : clic ouvre un composer rouge 12 px, tape ta note, Enter — elle s'attache au rectangle le plus proche.

Clic sur le badge → panneau latéral avec la liste des rectangles + notes → bouton Pousser sur kenboard : une seule tâche markdown (un blockquote par rectangle + ta note) plus un SVG d'annotations attaché à la tâche (squelette de la page viewport + tes rectangles rouges en surimpression), visible dans le modal détail. Esc ferme le panneau, encore Esc sort du mode.

VS Code Le ken pour l'éditeur

Voir les tâches du projet courant dans la barre latérale de VS Code, lire leur détail et changer leur statut sans quitter l'éditeur.

1. Télécharger

Chaque release attache l'extension : github.com/lduchosal/kenboard/releases → kenboard-vscode-<version>.vsix. Sa version suit celle de kenboard.

2. Installer

code --install-extension kenboard-vscode-<version>.vsix

Ou dans VS Code : vue Extensions → menu … → Install from VSIX… → choisir le fichier.

3. Configurer

Rien à saisir dans l'extension : elle lit la même configuration que la CLI ken — ken.ini et .ken, cherchés depuis la racine du workspace en remontant (les variables KEN_* priment). Si le dépôt n'est pas encore configuré, lancez-y une fois :

ken init "<Copy onboard link>"

Réglage optionnel kenboard.autoRefreshSeconds (défaut 60, 0 = désactivé) : rafraîchissement automatique de la liste et du détail ouvert.

4. Utiliser

Icône kenboard dans la barre d'activité → vue Tâches (todo / doing / review). Clic sur une tâche : détail rendu comme la vue plein écran du site. Clic droit : Move to… pour changer le statut, ou Ouvrir dans kenboard. Boutons de la vue : rafraîchir, ouvrir le board dans le navigateur.
