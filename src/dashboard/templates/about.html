À propos du kenboard

Projet kenboard {{ about.version }}

Tableau kanban et gestion de projet, pensé pour être piloté autant par des humains que par des agents LLM.

Les tâches sont rangées par catégories et projets, et suivent le flux todo → doing → review → done. Le board se pilote depuis le navigateur, depuis la CLI ken (agents, terminal), depuis l'extension navigateur et depuis l'extension VS Code — voir l'aide. Les tâches terminées alimentent un wiki généré par ken wiki.

Stack volontairement sobre : Flask + MySQL, SQL écrit à la main (pas d'ORM), validation Pydantic, JavaScript vanilla.
